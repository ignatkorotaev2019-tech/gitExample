# Лабораторная работа №2

## Тема

Работа с Visual Studio Code, Git, GitHub, Markdown и PlantUML.

## Описание проекта

Данный проект создан в рамках лабораторной работы №2.

В проекте используется язык программирования Python.

Программа выводит на экран сообщение:

**Hello, World!**

## Структура проекта

| Папка/файл | Назначение |
|---|---|
| `src` | Исходный код программы |
| `src/main.py` | Основная программа |
| `docs/diagrams` | Диаграммы PlantUML |
| `README.md` | Описание проекта |

## Используемые технологии

- Python
- Visual Studio Code
- Git
- GitHub
- Markdown
- PlantUML

## Запуск программы

Для запуска программы необходимо выполнить файл `src/main.py`.

Результат работы:
