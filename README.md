# Регистр учёта такси

## О проекте
Проект позволяет удобно обробатывать данные большого количества таксистов в фирме.

## Функционал проекта٩(｡•́‿•̀｡)۶ 

Основные функции системы:

- учёт водителей;
- учёт автомобилей;
- добавление информации;
- изменение информации;
- удаление информации;
- просмотр информации;
- поиск необходимых данных.

## Диаграмма функционала

Для описания функционала проекта используется язык **PlantUML**.

Диаграмма показывает основные функции системы и взаимодействие пользователей с системой.

## Структура проекта

| Папка/файл | Назначение |
|---|---|
| `src` | Исходный код программы |
| `src/main.py` | Основная программа |
| `docs/diagrams` | Диаграммы PlantUML |
| `README.md` | Описание проекта |

## Установка и запуск

### 1. Клонирование репозитория с GitHub

```bash
git clone https://github.com/ignatkorotaev2019-tech/gitExample.git
```

### 2. Переход в корень проекта

```bash
cd gitExample/Lab2
```

### 3. Создание виртуального окружения

**Windows:**

```text
python -m venv venv
```

**Linux/macOS:**

```bash
python3 -m venv venv
```

### 4. Активация виртуального окружения

**Windows (PowerShell):**

```text
.\venv\Scripts\Activate.ps1
```

**Linux/macOS:**

```bash
source venv/bin/activate
```
### 5. Запуск программы

**Windows:**

```powershell
python src/main.py
```

**Linux/macOS:**

```bash
python3 src/main.py
```
